# Frontend

React + TypeScript + Vite Web 应用。

## 启动

在本目录执行：

```bash
pnpm install
pnpm dev
```

默认访问 [http://localhost:5173](http://localhost:5173)。涉及真实数据时先按[项目启动说明](../../README.md)启动数据服务和后端。
