## 本地运行

- 文件功能默认关闭存储写入。设置 `STORAGE_ENABLED=true` 及 `STORAGE_S3_ENDPOINT`、`STORAGE_S3_BUCKET`、`STORAGE_S3_ACCESS_KEY`、`STORAGE_S3_SECRET_KEY`；使用专用私有、无版本控制/对象锁的桶。凭据只在环境中配置。
- 在 `apps/backend` 执行 `gradlew parserDistribution`，再执行 `docker build -t workspace-file-parser:0.2 build/parser`。基础 JRE 使用固定摘要；发布时应把 `FILE_PARSER_IMAGE` 配成已验收镜像摘要。
- `FILE_EXTRACTION_ENABLED=true` 开启后台提取。后端宿主机需要 Docker CLI 和创建受限容器的权限，生产部署方式仍需运维验收。
- `FILE_PURGE_ENABLED=true` 开启物理清理；默认关闭。仅清理数据库记录的精确对象引用。到期上传的容量补偿不依赖这个开关。
- 常规测试未提供 `RUSTFS_TEST_ACCESS_KEY` / `RUSTFS_TEST_SECRET_KEY` 和 `WORKSPACE_PARSER_TEST=true` 时，真实存储/容器测试会跳过，报告时必须说明。
